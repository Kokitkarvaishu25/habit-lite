# 🔥 Habit Lite

A sleek, dark-themed, web-based Habit Tracking application built with HTML, CSS, JavaScript, and Firebase (Authentication & Firestore).

Live Demo: [https://habit-lite.netlify.app](https://habit-lite.netlify.app)

## 🚀 Features
- 🔐 **Google Authentication**: Quick & secure sign-in with Firebase Auth.
- ⚡ **Real-time Synchronization**: Powered by Firebase Firestore.
- 🔥 **Streak Tracking**: Automatic daily streak calculations and motivational badges.
- 📊 **Dashboard & Metrics**: Keep track of total habits, completed habits today, and your best streak.
- 🎨 **Modern Dark UI**: Designed with CSS custom properties, glassmorphism, responsive layouts, and smooth animations.

## 🛠️ Tech Stack
- **HTML5 / CSS3 / JavaScript (ES6+)**
- **Firebase v8 SDK** (Auth & Firestore)
- **Google Fonts** ('Syne', 'DM Sans')

## 📁 Repository Structure

## 📦 How to Run Locally
1. Clone the repository:
   ```bash
   git clone <your-repository-url>
   ```
2. Open `index.html` in your web browser or serve via a local server (e.g., Live Server extension in VS Code).
